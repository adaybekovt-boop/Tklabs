# v0.17.3 — Security Enforcement

Release date: 07 August 2026  
Channel: preview  
Scope: browser policy, dependency review, secret scanning, and supply-chain evidence

## Changes

- Enforces a production-compatible Content Security Policy while running a stricter policy in report-only mode.
- Adds a bounded same-origin CSP report endpoint that records only sanitized directive metadata.
- Adds pull-request dependency review pinned to an immutable action commit.
- Scans tracked source files for high-confidence committed credential formats without printing secret values.
- Generates a CycloneDX SBOM for every validated commit and retains it as CI evidence.
- Centralizes Markdown URL sanitization and blocks executable or opaque protocols.

## Compatibility

The enforcing policy preserves the current Vinext runtime requirements. The stricter script policy remains observational until collected reports show that enforcing it will not break production. No database or user-data migration is required.
