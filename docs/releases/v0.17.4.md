# v0.17.4 — Repository Hygiene

Release date: 07 August 2026  
Channel: preview  
Scope: ownership, contribution evidence, testing structure, and release identity

## Changes

- Adds CODEOWNERS for production, AI, data, and workflow boundaries.
- Adds pull-request, bug, and feature templates with validation and rollback evidence.
- Documents unit, integration, browser, security, and release test layers.
- Moves obsolete v0.9.1 root merge documents into a clearly non-operative historical archive.
- Adds an executable release-consistency checker for package metadata, lockfile, runtime release, Service Worker cache, and release documentation.
- New regression coverage is organized by durable domain while historical release tests remain compatibility evidence.

## Compatibility

No runtime data migration is required. Repository administration settings remain owner-controlled and are not modified by application code.
