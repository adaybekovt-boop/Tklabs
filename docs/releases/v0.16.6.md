# v0.16.6 — Workspace Vault

**Channel:** Preview  
**Date:** 07 Aug 2026  
**Codename:** Workspace Vault

## Overview

Workspace Vault adds explicit data portability to TK LAB. Conversations, branch metadata, chat drafts, workspace artifacts, Erma Flow runs, and supported interface settings can be exported into one local JSON bundle, verified with SHA-256, and restored without sending the bundle to a server.

## Local backup

- A dedicated `/vault` page summarizes the amount and size of supported local workspace data.
- Export runs entirely in the browser and downloads one human-readable JSON document.
- The export includes a schema version, application version, timestamp, sorted entries, and SHA-256 digest.
- Only an explicit allowlist of TK LAB localStorage keys is included.
- Login sessions, authentication cookies, API keys, private tokens, and unrelated browser storage are never exported.

## Integrity and validation

- Imports are limited to 5 MB with additional per-entry bounds.
- The JSON structure, schema version, timestamp, key allowlist, value types, and digest are validated before any write.
- A changed or damaged bundle fails the SHA-256 integrity check and is rejected.
- Unsupported keys cannot be introduced through a Vault file.

## Restore modes

### Merge

Merge preserves existing supported keys and overwrites only keys present in the verified bundle.

### Replace

Replace removes all supported TK LAB workspace keys before restoring the verified bundle. Unrelated localStorage entries remain untouched.

Both modes require a second explicit press after selection. The interface shows the verified source version, export time, digest prefix, and item counts before restoration.

## Discoverability

Workspace Vault is linked from the mobile chat drawer and the site footer. The page is available without requiring a server-side data migration or new API endpoint.

## Compatibility

- Includes Safe Prompt Branches from v0.16.5.
- Preserves Erma Flow, Agent Runs, Artifact Studio, projects, response versions, and current API contracts.
- The Service Worker cache namespace is bumped to `tklabs-v0.16.6-static`.

## Security and privacy notes

The backup can contain complete conversation and artifact text. It should be handled as a private document. TK LAB does not upload, inspect, or synchronize the file.

## Known limitations

- Automatic scheduled backups are not included.
- Cloud synchronization is not included.
- Import replaces whole approved storage keys rather than merging individual conversations or artifacts inside those keys.
