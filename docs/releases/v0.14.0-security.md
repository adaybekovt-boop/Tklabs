# v0.14.0 tool boundary checklist

This companion checklist records the intentionally excluded capabilities for the first NVIDIA tool release.

- No mutating tools.
- No shell or process execution.
- No filesystem reads or writes.
- No arbitrary network URLs.
- No dynamic code evaluation.
- No parallel tool calls.
- No autonomous background loop.
- No tool arguments or results in server logs.
- No full local archive upload or persistence.
- Any future write action requires a separate allowlist entry and explicit user confirmation.
