# v0.20.10 — Mobile Fixed Layers

Channel: preview  
Date: 8 August 2026

v0.20.10 is a mobile reliability patch for Trust Architecture. It fixes the class of bugs where consent dialogs, bottom navigation, or workspace sheets were visually attached to a long page or chat rather than to the current browser viewport.

## What changed

- TermsGate now renders through a `document.body` portal and uses a full `100dvh` mobile shell.
- Only the agreement document scrolls; the legal header and accept/decline controls stay inside the visible viewport and respect safe-area insets.
- Public AppDock is rendered as an independent body-level fixed layer and remains visible while long pages scroll.
- Mobile Workspace Switcher is also a body-level fixed layer, follows the visual viewport/keyboard inset, and reserves space in the chat workspace.
- Chat/Trust overlays and the mobile chat drawer use one reference-counted document scroll lock so the background cannot drift underneath a blocking surface.
- Overlay z-index ordering is explicit: public navigation < workspace navigation < sheets < drawer < TermsGate.
- Browser Assurance now includes long-page TermsGate, persistent public navigation, and persistent workspace navigation scenarios on mobile Chromium/WebKit.
- Service Worker cache namespace rotates to `v0.20.10-mobile-fixed-layers-r1` so the corrected mobile shell is not hidden behind an older static cache.

## Required deployment changes

There are no new D1 migrations or new required secrets in v0.20.10. Normal release validation and Cloudflare deployment are sufficient.

## Known preview limits

- Agreement text remains scrollable inside the legal panel by design; the acceptance controls themselves remain visible.
- When the software keyboard is open, the Trust just-in-time disclosure is hidden so it does not compete with the composer; the workspace dock follows the visual viewport.
- Workspace Sync remains server-side encryption at rest, not end-to-end encryption.
- A strict nonce-only script CSP remains report-only for the current Next/Vinext hydration path.
