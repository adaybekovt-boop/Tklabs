# v0.16.0-beta.1 — ERMA NOVA

**MAJOR UPDATE · PRE-RELEASE**

Erma Nova starts the transition from a single chat surface to an intelligent workspace for bounded agent runs, editable artifacts, references, and project work.

## Included in beta.1

- Erma Nova Workspace with Chat, Artifacts, and Agent Runs surfaces.
- Artifact Studio with local-only storage, explicit size limits, version snapshots, restore, duplicate, delete confirmation, and Markdown/TXT/JSON/CSV export.
- Agent Run Protocol 2.0 with typed events and a maximum of six planned steps.
- Compatibility with v0.15.0 conversations, projects, drafts, branches, versions, streaming, Stop, and local archive.
- A dedicated preview release record with codename, stability, known issues, and migration notes.

## Security boundaries

- No shell or eval execution.
- No arbitrary filesystem access.
- No arbitrary URL tool input.
- No hidden autonomous loop.
- Mutating agent actions are not enabled in beta.1.
- Artifact data remains on the current device.

## Known limitations

- The Agent Run timeline is a foundation surface; live run wiring will expand in the next beta patches.
- Account synchronization is not included.
- PDF and DOCX export are not included.
- Existing chat messages are not automatically converted into artifacts yet.

## Migration

No destructive migration is required. Existing local chat data keeps its current schema. Artifact Studio writes to the separate `tklabs.workspace-artifacts.v1` localStorage namespace.
