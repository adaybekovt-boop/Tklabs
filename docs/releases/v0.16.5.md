# v0.16.5 — Safe Prompt Branches

**Channel:** Preview  
**Date:** 07 Aug 2026  
**Codename:** Erma Flow

## Overview

v0.16.5 replaces destructive prompt editing with a branch-preserving workflow. Editing an older user request now keeps the original conversation intact, creates a separate continuation with the exact context that existed before the selected message, and places the original prompt into the composer for revision.

## Safe prompt editing

- The current conversation is saved before any edit branch is created.
- Editing a prompt in the middle of a conversation creates a child branch ending immediately before that prompt.
- The original prompt is restored into the composer as a draft, so the user can revise it before submission.
- The original conversation remains available in the archive and can be reopened from the composer status banner.
- Editing the first prompt starts a clean branch while preserving the complete original conversation in history.
- Submitting the edited prompt marks the branch as active without removing the recovery link.

## Context correctness

The new branch contains only messages that occurred before the edited prompt. Old assistant answers and later user turns are never included in the new request context, preventing contradictory continuations and accidental context leakage between branches.

## Mobile and desktop behavior

The same editing workflow is used by desktop action menus, mobile action sheets, and long-press message actions. The composer displays a compact branch-preserving status panel with the source conversation title and a direct return action.

## Compatibility

- Existing conversations and branch metadata remain compatible.
- No server migration or API contract change is required.
- Erma Flow, Agent Runs, Artifact Studio, response versions, projects, attachments, and local drafts remain unchanged.
- The Service Worker cache namespace is bumped to `tklabs-v0.16.5-static` so outdated static assets are removed during activation.

## Known limitations

- Branch relationships are stored, but the archive does not yet render a full visual conversation tree.
- Conversations and edited branches remain local to the current browser profile.
- Attachments from the original prompt are not automatically recreated in the edited draft.
