# v0.23.4 — Erma Alive & Vision

Released as the final quality gate for the v0.23 cycle.

## What changed

- LaTeX emitted as `\[...\]` or `\(...\)` is normalized before `remark-math` and KaTeX rendering, so aligned equations render instead of appearing as raw control text.
- Erma uses one adaptive character prompt instead of rigid role modes or forced catchphrases. Practical tasks stay direct; philosophical depth is used only when relevant.
- Web Speech final results are reconstructed by result index and adjacent duplicates are removed before updating the composer.
- The single attachment control supports camera capture, image/file selection, and pasted screenshots.
- JPEG, PNG, and WebP images are resized and compressed locally before transmission.
- Image requests route automatically to the hidden NVIDIA multimodal execution model `qwen/qwen3.5-122b-a10b`; the public Erma text catalog remains unchanged.
- NVIDIA receives real multimodal `image_url` parts rather than image placeholders in the text prompt.
- Image bytes are validated separately from text context and visual content is treated as untrusted user data.
- Vision fails closed: if multimodal processing is unavailable, TK LAB does not fall back to a text-only model and does not guess image contents.

## Limits

- Vision requires the configured external NVIDIA model provider. TK LAB does not claim on-device image inference.
- Supported image formats are JPEG, PNG, and WebP.
- Requests are bounded to at most two images and three total attachments, with per-image and combined payload limits.
- Voice recognition quality still depends on the browser/OS Web Speech implementation; v0.23.4 fixes duplicate result assembly rather than replacing that recognition engine.
- The deterministic math engine remains intentionally bounded and is not a universal computer algebra system.

## Data handling

Submitted images are prepared locally on the device, then sent through the TK LAB Worker to the external multimodal model provider when the user submits the request. Image content is not appended to the textual provider prompt. Product Facts disclose this route explicitly.

## Migration and operations

- No D1 migration is added by v0.23.4.
- No new production secret is required; vision uses the existing NVIDIA API key configuration.
- `package.json`, `package-lock.json`, `lib/release-version.ts`, Patch Notes, and the Service Worker cache namespace are synchronized at `v0.23.4`.
- Browser Assurance covers the reported bracket-style LaTeX failure and image-only composer submission after client-side compression.
