# v0.16.0-beta.3 — Interface Reliability

**MAJOR UPDATE · PRE-RELEASE**

This patch aligns the public interface with the active Erma Nova preview and removes several mobile regressions introduced as the workspace expanded.

## Current release consistency

- Added one version source of truth for the active preview.
- The home page now reads the current preview instead of the last stable v0.15.0 entry.
- The workspace badge, Patch Notes, and release metadata now publish v0.16.0-beta.3 consistently.
- Removed stale beta.1 labels from the current Agent Runs and Patch Notes surfaces.

## Workspace interface fixes

- Moved RU/EN into the Erma Nova header instead of rendering a fixed control over the mobile interface.
- Made workspace tabs horizontally safe on narrow screens.
- Added tablist, tab, tabpanel, aria-selected, aria-controls, and labelled panel relationships.
- Protected workspace state restoration when localStorage is blocked or unavailable.

## Artifact Studio mobile fixes

- Added a mobile artifact picker so existing documents remain reachable after creating more than one artifact.
- Added mobile version history with restore actions.
- Added accessible labels and live save status.
- Hardened export cleanup and delete-confirmation state.

## Compatibility

- Existing conversations, drafts, projects, branches, and artifact storage remain unchanged.
- No public API, JSON, SSE, provider, quota, or authentication contract changed.
- The stable release history remains available below the active preview.
