# v0.13.0 — True Chat and Streaming

Дата выпуска: 6 августа 2026

## Основные изменения

- AI API принимает полную multi-turn историю сообщений пользователя и ассистента.
- NVIDIA Chat Completions использует SSE streaming с событиями `start`, `delta`, `meta`, `error` и `done`.
- Ответ отображается по мере генерации; Stop прерывает upstream-запрос и сохраняет уже полученную часть ответа.
- Server-side context manager контролирует токен-бюджет, сохраняет последние сообщения и сворачивает старый контекст в memory summary.
- Retry восстанавливает предыдущую историю без дублирования текущего пользовательского сообщения.
- Сообщения можно исключать из контекста и возвращать обратно; выбор хранится в локальном архиве.
- Интерфейс показывает стадии подключения, анализа и генерации, оценку контекста, TTFT и usage metadata.
- JSON transport сохранён для обратной совместимости. Clodex использует тот же multi-turn контекст, но пока остаётся на JSON.

## Проверка

Релиз покрыт тестами multi-turn контекста, SSE transport, квот, отмены запроса и определения языка ответа.
