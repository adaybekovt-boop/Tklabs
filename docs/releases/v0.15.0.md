# v0.15.0 — Calm Workspace and Practical Agent

Release date: 6 August 2026

## Summary

v0.15.0 reduces interface noise and turns the existing read-only tool layer into a faster, more understandable practical agent. The release keeps local conversations, projects, branching, response versions, streaming, Stop, text attachments, and the six safe tools while removing provider diagnostics from the normal user flow.

## AI chat

- Added `Erma · Auto` as the recommended user-facing route.
- Rebuilt the chat shell around history, transcript, and composer instead of permanent controls.
- Removed the always-visible response-mode toolbar and raw context counter.
- Kept a context warning only when the conversation approaches its limit.
- Replaced persistent message action rows with explicit `•••` menus.
- Replaced raw tool cards with a calm expandable Agent Activity section.
- Removed provider ID, request ID, latency, TTFT, and token diagnostics from normal messages.
- Reduced the desktop workspace drawer to Activity and Context.
- Kept model comparison, reasoning, response format, files, and projects under Advanced settings.
- Kept an explicit mobile history button and language control.

## Agent runtime

- Added deterministic direct recipes for arithmetic, service status, release comparison, documentation, model capabilities, and local archive requests.
- Direct recipes bypass the NVIDIA planner.
- Ambiguous tool requests use the Lite planner regardless of the final answer model.
- Reduced planner output to 256 tokens.
- Reduced normal planner allowance to two calls and one round; explicit comparisons may use up to four calls.
- Kept the server allowlist, closed JSON Schemas, per-tool timeout, sequential execution, and the ban on arbitrary URLs, shell commands, filesystem access, and mutating actions.

## Models and prompts

- Added server-side Auto routing helpers for Lite, Core, and Pro.
- Rewrote Erma prompts to remove requests to reveal hidden reasoning, claims of having no limits, mandatory catchphrases, and forced lore.
- Erma styling may affect tone only; it cannot change safety, tool permissions, or answer quality.

## Site structure

- Reduced desktop primary navigation to AI chat, Models, Updates, and Status.
- Localized desktop navigation labels.
- Merged the Access explanation into the Models page.
- Preserved `/access` as a redirect to `/models#access`.
- Reworked the Models page around Erma Auto, concrete tiers, capabilities, and access.

## Compatibility

- Existing local conversations, projects, branches, response versions, drafts, and sanitized tool traces remain compatible.
- Existing API transport and read-only tool names remain unchanged.
- No vision, write tools, shell execution, autonomous background agent, or cloud archive sync was added.
