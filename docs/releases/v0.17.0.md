# v0.17.0 — Reliability Foundation

Release date: 07 August 2026  
Channel: preview  
Scope: provider lifecycle, bounded streaming, security baseline, supply-chain controls

## Purpose

v0.17.0 closes the highest-risk reliability debt found during the repository audit. Provider cancellation and timeout ownership previously ended when HTTP response headers arrived, even though an NVIDIA or Clodex body could continue streaming or parsing afterward. The release moves that ownership around the complete response-consumption lifecycle.

## Provider lifecycle

`withProviderResponse` now owns one composed abort scope from request start until the provider body has been completely consumed.

The scope:

- forwards the browser or route `AbortSignal` for the full JSON/SSE lifecycle;
- applies a total provider deadline;
- optionally applies an idle deadline refreshed by received stream chunks;
- aborts the upstream fetch when either deadline expires;
- removes timers and external abort listeners after success, failure, or cancellation;
- reports total and idle timeout reasons separately.

NVIDIA non-streaming generation, NVIDIA tool planning, and Clodex fallback all use the same lifecycle helper.

## Bounded NVIDIA streaming

NVIDIA streaming now uses:

- a 120-second total deadline;
- a 20-second idle deadline;
- a 96,000-character accumulated-answer ceiling;
- a 12,000-character rolling safety window during streaming;
- one complete final safety evaluation before returning the normalized answer.

The rolling window avoids repeatedly concatenating and rescanning the entire generated answer for every provider delta. Answer chunks are joined once at finalization.

## Failure transparency

Fallback metadata distinguishes:

- `provider_total_timeout`;
- `provider_idle_timeout`;
- `nvidia_output_too_large`;
- existing provider, configuration, and safety failures.

A partial answer that reached the client remains preserved and labelled by the existing stream interruption contract.

## Regression coverage

The integration suite now verifies that:

- a provider body that hangs after headers is aborted by the total deadline;
- external cancellation remains linked after headers;
- arriving chunks refresh the idle deadline;
- an idle stream is aborted;
- external abort listeners are removed after successful response consumption;
- NVIDIA accumulation and streaming safety scans remain bounded.

## Security and dependency controls

- Existing GitHub Actions are pinned to immutable commit SHAs.
- CodeQL analyzes JavaScript and TypeScript on `main`, agent branches, pull requests, and a weekly schedule.
- Dependabot monitors npm and GitHub Actions dependencies weekly.
- `Content-Security-Policy-Report-Only` establishes a non-blocking CSP baseline for production observation before enforcing the policy.

## Data and migration impact

There are no D1 schema, Durable Object storage, account, conversation archive, or Workspace Vault format changes.

The Service Worker cache namespace changes to `tklabs-v0.17.0-static`; older TK Labs static caches are removed during activation.
