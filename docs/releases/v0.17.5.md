# v0.17.5 — Release Safety

Release date: 07 August 2026  
Channel: preview  
Scope: migration compatibility, single deployment writer, canary, rollback, and release evidence

## Changes

- Blocks unreviewed destructive D1 migrations and requires an explicit compatibility marker plus rollback plan.
- Requires repository variable `TKLABS_DEPLOY_WRITER=github-actions` before production deploy, canary, or rollback.
- Adds a manual Cloudflare Worker version canary workflow with bounded traffic percentages.
- Adds a deliberate rollback workflow requiring a known-good version ID and recorded reason.
- Retains production, canary, rollback, SBOM, integration, and browser evidence as bounded artifacts.
- Synchronizes package metadata, lockfile, runtime release identity, preview notes, documentation, and Service Worker cache at v0.17.5.

## Required owner action

Disable Cloudflare Git Integration for the `tkai` Worker and set `TKLABS_DEPLOY_WRITER=github-actions` before merging. Repository code cannot change this owner-only Cloudflare setting.

## Data compatibility

No user-data format changes are included. Migrations must follow expand → migrate → contract and remain compatible with the previous known-good Worker until a later reviewed contraction release.
