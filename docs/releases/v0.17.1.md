# v0.17.1 — Architecture Split

Release date: 07 August 2026  
Channel: preview  
Scope: demo route orchestration and chat request boundaries

## Changes

- `app/api/demo/route.ts` is now a thin transport selector.
- Request validation, authentication, safety checks, context preparation, and quota reservation live in `request-context.ts`.
- Non-streaming provider generation and fallback policy live in `json-responder.ts`.
- Streaming ownership lives in the `DemoStreamSession` class.
- Chat request state, event-stream parsing, retry header handling, context conversion, response snapshots, and model selection are separated into `hooks/chat-request/*`.
- Regression contracts prevent provider and quota implementation details from returning to the route.

## Compatibility

No D1, Durable Object, account, archive, or Workspace Vault migrations are required. Public API payloads and SSE event names remain unchanged.
