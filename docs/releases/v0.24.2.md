# v0.24.2 — Google Direct Grounding

**Date:** 2026-08-09  
**Channel:** Preview / Beta  
**D1 migration:** None

## Summary

v0.24.2 changes the factual web-answer path so eligible factual, current-information, and research prompts can use the official Gemini Interactions API with Google Search grounding as the answer source itself.

Instead of discarding Google's grounded model output and asking NVIDIA to rewrite the retrieved evidence, TK LAB now sends the privacy-minimized current user turn to Google Search grounding and, when Google returns a complete grounded response, displays that response directly in Erma.

This is the official API-backed equivalent of the desired Google-grounded answer flow. It does **not** scrape the consumer `AI Overview` block from google.com, and wording can differ from what the Google Search app shows.

## Changes

- Added a direct Google Search grounding transport using the Gemini Interactions API.
- Eligible `fact_lookup`, `fresh_information`, and `research` routes send only the minimized current user turn to Google; the full conversation history is not sent to the search provider.
- A complete Google grounded answer bypasses NVIDIA rewriting and is streamed directly into the Erma response.
- Direct pass-through requires evidence that Google actually executed web search plus URL citations and Search Suggestions. Incomplete grounding falls back to the existing Erma verification pipeline.
- Google Search Suggestions are rendered in a sandboxed attribution surface and returned citations are exposed as source links.
- Added `google-grounding` response provenance so product telemetry can distinguish direct Google-grounded answers from NVIDIA and local fallbacks.
- Local archive sanitation now preserves bounded Google grounding metadata, citations, Search Suggestions, and the `search_web` tool trace so attribution survives reloads.
- Direct pass-through remains behind TK LAB safety policy. Blocked, restricted, and high-impact prompts continue through the normal safety/synthesis path.
- Existing Kazakhstan entity handling, source ranking, privacy-minimized search, Google Custom Search fallback, and Brave fallback remain available.

## Privacy and provider behavior

The direct Google route sends the privacy-minimized current turn, not the complete chat history. It is still external-provider processing: under Google's current Grounding with Google Search terms, prompts, contextual information, and generated output used for grounded results and Search Suggestions are stored for 30 days, and that storage cannot be disabled for this feature.

The TK LAB Product Facts, Privacy Policy, and Subprocessors disclosure have therefore been updated. The legal bundle version is `2026-08-09` with a new content digest so the consent surface can distinguish the changed processing terms.

## Reliability behavior

Google quota and rate limits still apply. If direct Grounding with Google Search returns HTTP 429 or another transient provider error, TK LAB cannot bypass the exhausted Google quota; it falls back to the existing web path when another configured route is available.

The direct path intentionally fails closed to the older verification route when the Google response is missing citations or Search Suggestions rather than presenting an unattributed Google-generated answer as grounded.

## Configuration

A production Cloudflare Worker must already have one of these encrypted secrets:

- `GOOGLE_GEMINI_API_KEY`
- `GEMINI_API_KEY`

`GOOGLE_GROUNDING_MODEL` remains a normal server-side runtime variable. API keys are not browser-exposed, committed to the repository, or passed as public Worker variables.

## Verification

Regression coverage includes:

- direct user-turn forwarding to Google Search grounding;
- exact Google answer pass-through without NVIDIA rewriting;
- parsing of executed search queries, citations, and Search Suggestions;
- rejection of incomplete attribution;
- safe response metadata transport;
- isolated Search Suggestions rendering;
- local archive preservation of Google grounding attribution;
- existing product-truth storage/provider boundaries;
- legal-bundle consistency after the Google-grounding disclosure.
