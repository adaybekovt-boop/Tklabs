# v0.17.2 — Browser Assurance

Release date: 07 August 2026  
Channel: preview  
Scope: browser-level regression coverage

## Changes

- Adds an isolated Playwright workflow for desktop Chromium, mobile Chromium, and mobile WebKit.
- Starts the application through the development-only local preview boundary; production authentication behavior is unchanged.
- Mocks the public AI SSE endpoint so browser tests never consume real provider quota or credentials.
- Verifies ordered streaming deltas, response metadata, transcript rendering, and prompt submission.
- Verifies locale cookie/localStorage synchronization and the root document language.
- Verifies the mobile composer and horizontal overflow boundaries.
- Verifies the offline page and installable manifest.
- Retains traces, screenshots, videos, and HTML reports only as bounded CI evidence.

## Compatibility

No database, Durable Object, account, archive, or Workspace Vault migrations are required. The browser workflow is independent from production deployment.
