# v0.16.0-beta.2 — ERMA NOVA Architecture Foundation

**MAJOR UPDATE · PRE-RELEASE**

This beta establishes the architecture boundaries needed to continue expanding Erma Nova without turning the public AI endpoint into a monolith.

## Architecture

- Split `/api/demo` into focused request contracts, HTTP response mapping, quota lifecycle, and provider fallback policy modules.
- Reduced the route handler from roughly 558 to 405 lines while preserving its public JSON and SSE contracts.
- Removed direct rate-limit persistence, identity derivation, Clodex provider configuration, and validation-message formatting from the route.
- Added one idempotent quota interface for both public and privileged requests.

## Safety and behavior preserved

- Request IDs, origin checks, prompt and attachment validation, context limits, and safety refusals are unchanged.
- Public quota reservations still commit only after delivered provider output and release when no output is delivered.
- Interrupted streams still preserve partial output, return explicit metadata, and settle quota consistently.
- NVIDIA remains the primary provider with labelled Clodex or local fallback behavior.
- Provider reasoning and private configuration remain server-only.

## Regression protection

- Added contract tests for normalization, fallback metadata, provider failure classification, and route boundaries.
- The route now has a 450-line architecture budget.
- Tests prevent the route from directly importing rate-limit persistence or Clodex fallback configuration.
- Added `docs/ARCHITECTURE.md` with ownership rules, invariants, and the next safe extraction sequence.

## Migration

No user migration is required. Existing conversations, projects, drafts, local archives, and beta.1 artifacts remain unchanged.

## Known limitations

- Agent Run live wiring remains in progress.
- Artifacts remain local to the current device.
- Browser-level Playwright coverage is planned for a later beta; the current validation gate covers unit, integration, production build, performance budget, and Worker dry-run checks.
