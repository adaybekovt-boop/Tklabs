# v0.16.0-beta.4 — Mobile Chat Rebuild

**MAJOR UPDATE · PRE-RELEASE**

This patch rebuilds the mobile AI chat as a dedicated product surface instead of a compressed desktop workspace.

## Mobile shell

- Removed the duplicate workspace header while Chat is active on small screens.
- Added one compact conversation header with history, title, status, and new-chat actions.
- Added a full-height left navigation drawer with conversation search, projects, workspace shortcuts, theme, and language controls.
- Added dedicated mobile back headers for Artifacts and Agent Runs.

## Composer

- Added a mobile-only composer that is selected by viewport instead of rendering the desktop composer at reduced width.
- Attachments are visible above the textarea and can be opened or removed directly.
- The plus button now means add a file instead of opening an unrelated settings panel.
- The primary button changes between Voice, Send, and Stop based on the current state.
- Model, response mode, effort, and deep reasoning live in one focused bottom sheet.
- Offline, voice, attachment, and recording states remain visible without replacing the composer.

## Message stream

- Added a mobile-only transcript renderer while keeping the established desktop renderer unchanged.
- User messages use compact bubbles with a stricter readable width.
- Assistant answers render as a clean text stream instead of large bordered cards.
- Copy and regenerate remain directly accessible; secondary actions move into a bottom action sheet.
- Long press opens message actions on touch devices.
- Model comparisons render as stacked expandable sections on mobile.

## Compatibility

- Existing conversations, drafts, projects, versions, attachments, and artifacts remain compatible.
- The `/api/demo` JSON and SSE contracts are unchanged.
- Desktop chat components remain the stable fallback during the mobile migration.

## Known limitations

- Editing an older user prompt still moves the text into the composer. Branch-preserving edit-and-resubmit is planned for the next patch.
- Browser-level Playwright coverage is not connected yet.
