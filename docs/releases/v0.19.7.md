# v0.19.7 — Workspace Evolution

Release date: 2026-08-08
Channel: preview

Workspace Evolution is the complete v0.19.0–v0.19.7 major cycle. It consolidates mobile navigation, stabilizes the chat viewport, adds structured long-context memory, unlocks bounded multi-round Erma Flow, expands document/artifact workflows, adds optional encrypted workspace snapshots, and makes PWA updates explicit.

## Included stages

- v0.19.0 — Workspace Evolution Foundation
- v0.19.1 — Mobile Shell 2.0
- v0.19.2 — Mobile Chat Pro
- v0.19.3 — Chat Runtime 3.0
- v0.19.4 — Erma Flow 2.0
- v0.19.5 — Files & Artifact Workspace
- v0.19.6 — Optional Workspace Sync
- v0.19.7 — PWA & Reliability

## Safety boundaries

Erma Flow remains read-only and bounded. Workspace sync is opt-in and fail-closed. Private/API responses remain outside the Service Worker cache. D1 sync storage contains encrypted snapshot payloads plus bounded metadata. Existing auth, origin, request-size, migration-safety, security scanning, and release gates remain required.

## Migration

Apply `drizzle/0001_workspace_sync.sql` before enabling sync and configure a dedicated `WORKSPACE_SYNC_SECRET` of at least 32 characters. If the secret is absent, sync reports unavailable and local data remains unchanged.
