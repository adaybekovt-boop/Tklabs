# v0.16.7 — Profile Studio

**Channel:** Preview  
**Date:** 07 Aug 2026  
**Focus:** profile clarity, mobile navigation, local-data safety, and responsive polish

## Overview

Profile Studio rebuilds the account experience on phones and desktop. The profile is no longer a collection of separate blocks: it now works as one account hub with clear navigation, visible access state, a responsive membership card, and direct routes to AI chat, Workspace Vault, release history, and on-device data controls.

## Mobile profile

- Added a new visual profile hero with avatar, role, current release, AI access, Clodex state, and archive state.
- Replaced the old compact link row with a clear two-column action grid.
- Added direct actions for AI chat, Workspace Vault, release history, and local data.
- Removed the outdated hard-coded link to the v0.11.1 profile release.
- The actual current release is read from `CURRENT_RELEASE_VERSION`.
- The membership card is now available on mobile instead of being hidden with the desktop profile sections.

## Desktop profile

- Added an in-page profile section navigator.
- Rebuilt the identity area as a visual account hub with avatar, role, release badge, and action cards.
- Reorganized the page into Membership, Account Overview, Access & Limits, and On-device Data sections.
- Added explanatory text to access cards so status values are easier to understand.
- Improved spacing, hierarchy, focus states, and responsive behavior.

## Membership card

- Added a mobile-specific aspect ratio and smaller responsive spacing.
- Preserved pointer tilt, spring motion, flip interaction, and reduced-motion behavior.
- Added explicit `aria-describedby` help text.
- Preserved touch scrolling with `touch-action: pan-y`.
- Reduced small-screen text pressure and truncates long names, e-mail addresses, and capability labels safely.

## Mobile bottom navigation

- Promoted AI chat to a central primary action.
- Added clearer active states and a secondary active indicator.
- Added grouped sections with short descriptions.
- Added Workspace Vault to the workspace section.
- Removed the duplicate Access navigation item that competed with Models while keeping the legacy route available.
- Improved focus rings, safe-area spacing, and sheet accessibility.

## On-device data

- Added a prominent Workspace Vault card explaining the difference between a full workspace backup and conversation-only export.
- Renamed the quick export action to clarify that it exports conversations only.
- Added automatic expiration for destructive confirmations.
- Added timer cleanup when the profile is unmounted.
- Appends temporary download links to the document before clicking, improving compatibility with Safari-like browsers.
- Reset now clears the known local chat preference keys together with per-conversation drafts.

## Cache bump

The Service Worker cache version is bumped to:

```text
tklabs-v0.16.7-static
```

Old TK LAB cache namespaces are removed when the new worker activates.

## Validation

The release adds static regression coverage for:

- responsive profile hierarchy;
- mobile membership-card availability;
- Workspace Vault discoverability;
- conversation-only export wording;
- central mobile AI navigation;
- grouped secondary navigation;
- removal of the duplicate Access item;
- `v0.16.7` release and Service Worker cache versions.

## Known limitations

- Profile data remains local to the browser unless the user manually exports and imports Workspace Vault.
- Card tilt is intentionally disabled for touch pointers and reduced-motion users.
- The bottom navigation remains mobile-only; desktop continues to use the top navigation.
