# v0.12.0 — PWA, Performance, and AI Language

Release date: 2026-08-06

## Русская версия

### Язык AI

- Ответ больше не привязан к языку интерфейса.
- Язык определяется по текущему сообщению пользователя.
- Русский и английский распознаются явно.
- Другие естественные языки получают строгую инструкцию отвечать на языке текущего запроса, а не на языке интерфейса.
- Русские запросы с API-названиями, моделями и кодом остаются русскоязычными.
- Испанские, казахские, китайские и другие запросы не преобразуются в английские.
- Код, URL и содержимое прикреплённых файлов не меняют язык основного пользовательского запроса.
- Явная просьба ответить на другом языке имеет приоритет.
- NVIDIA и Clodex используют один языковой контракт.
- Safety, reasoning privacy и provider filtering не ослаблены.

### PWA и offline

- Добавлен версионный service worker.
- Статические ресурсы доступны из локального кэша.
- При отсутствии сети навигация получает отдельную offline-страницу.
- API, auth, admin и HTML-ответы не сохраняются в кэше.
- Ответы с `private`, `no-store` и `set-cookie` не кэшируются.
- Добавлены install prompt, standalone manifest, maskable icon и shortcuts.

### Производительность

- Удалена зависимость главной страницы от внешних Google-hosted изображений.
- Hero и laboratory artwork заменены локальными SVG.
- Hero загружается с высоким приоритетом, второе изображение — лениво.
- CI проверяет общий JavaScript, gzip-размер, самый большой chunk, CSS и изображения.
- CI выполняет Cloudflare Worker dry-run после production build.
- Production deploy использует тот же `npm run check`, поэтому performance budget блокирует публикацию слишком тяжёлой сборки.

## English version

### AI language

- Replies are no longer tied to the interface locale.
- Language is inferred from the current user message.
- Russian and English are detected explicitly.
- Other natural languages receive a strict instruction to reply in the language of the current request rather than the interface locale.
- Russian requests containing API names, model names, and code remain Russian.
- Spanish, Kazakh, Chinese, and other requests are not converted into English.
- Code, URLs, and attached file bodies cannot change the language of the main user request.
- An explicit request for another response language takes priority.
- NVIDIA and Clodex use one shared language contract.
- Safety, reasoning privacy, and provider filtering remain unchanged.

### PWA and offline

- Added a versioned service worker.
- Static resources remain available from a local cache.
- Navigation falls back to a dedicated offline page when the network is unavailable.
- API, authentication, administration, and HTML responses are not cached.
- Responses marked `private`, `no-store`, or `set-cookie` are never stored.
- Added an install prompt, standalone manifest, maskable icon, and shortcuts.

### Performance

- Removed the home page dependency on externally hosted Google images.
- Replaced hero and laboratory artwork with local SVG assets.
- The hero loads at high priority while the secondary image loads lazily.
- CI enforces total JavaScript, gzip size, largest chunk, CSS, and image budgets.
- CI runs a Cloudflare Worker dry-run after the production build.
- Production deployment runs the same `npm run check`, so an oversized build cannot be published.
