# v0.16.9 — Interface Polish

Release date: 7 August 2026  
Channel: preview

## Scope

This corrective release audits the interface changes committed after v0.16.8 and restores the quality contracts that were skipped by the direct design update.

## Fixes

- Restores a real accessible heading for ConversationArchive so `aria-labelledby` never references a missing node.
- Returns page scrolling to one document-level owner instead of making both `html` and `body` vertical scroll containers.
- Restores visible Known Issues and Migration Notes panels in Patch Notes.
- Removes the unused ConversationArchive icon import introduced by the design roll-up.
- Keeps the refreshed Erma Flow, Playground, Status, Patch Notes, and site-chrome design while adding regression coverage around the corrected behavior.

## Release and cache

- Application release: `v0.16.9 — Interface Polish`.
- Service Worker cache: `tklabs-v0.16.9-static`.
- Previous TK Labs static cache namespaces are deleted when the new Service Worker activates.
