# v0.21.15 — Erma Intelligence Engine

Release channel: preview  
Date: 2026-08-08

## Scope

v0.21.15 completes the v0.21.0–v0.21.15 Intelligence Engine cycle. Erma now routes tasks before generation, can use bounded live-web research when configured, searches canonical TK LAB policy/release knowledge, verifies supported mathematics deterministically, retrieves relevant attachment chunks, tracks evidence provenance, and chooses Erma Auto tiers by task complexity.

## Intelligence pipeline

`request → safety → cognitive route → dynamic context → bounded planner → tools → evidence → verifier → optional critic council → answer intelligence → model response`

The model is not the authority for current external facts, TK LAB legal/product facts, deterministic calculations, document retrieval, or sandbox execution claims. Those claims must be grounded in the corresponding evidence layer.

## Web Intelligence

Live search is optional and requires the server-only `BRAVE_SEARCH_API_KEY`. The model cannot send an arbitrary URL to the page opener: `open_web_result` accepts only IDs emitted by `search_web` in the same request. The gateway validates schemes, credentials, ports, literal local/private hosts, redirects, response size, and text content types. Retrieved web text is untrusted data and cannot override system or policy instructions.

This is a text research gateway, not a full JavaScript browser. Client-rendered pages may yield incomplete extracts. The gateway does not claim universal SSRF elimination or browser automation.

## TK LAB Knowledge Brain

Canonical searchable sources include User Agreement, Privacy, Acceptable Use, AI Transparency, Subprocessors, Security, Product Facts/data routes, and release history. Policy/release answers should include canonical document/release versions and links where available rather than relying on model memory.

## Math & LaTeX

The deterministic engine supports bounded arithmetic, quadratic equations, descriptive statistics, square determinants up to 4×4, and derivatives/integrals of numeric polynomials. It does not use `eval` and is not a universal CAS. Assistant math can be rendered with KaTeX/MathML using inline `$...$` and display `$$...$$` notation.

## Documents

Validated request attachments are split into bounded overlapping chunks and searched only for relevant fragments. This tool does not introduce a new server-side document database. Document text remains untrusted user data, and answers should attribute evidence to the document/chunk actually retrieved.

## Memory

The new server-side layered view contains working, episodic, and semantic conversation context, but its declared persistence is `request-context-only`. Existing Local/Synced/Ephemeral product storage modes remain authoritative for durable workspace behavior.

## Code Lab boundary

The application Worker never executes user code. `run_code_sandbox` is available only to the privileged code path and only when a separate HTTPS sandbox is configured through `CODE_SANDBOX_URL` and `CODE_SANDBOX_TOKEN`. Requests specify network disabled, temporary filesystem, and wall-time/memory/process limits. Without that external sandbox configuration, execution fails closed and Erma must not claim code or tests ran.

## Configuration

Optional new server-only settings:

- `BRAVE_SEARCH_API_KEY` — enables live Web Intelligence.
- `CODE_SANDBOX_URL` and `CODE_SANDBOX_TOKEN` — enable isolated Code Lab execution.

There are no new D1 migrations in v0.21.15.

## Verification

The release includes route, web-gateway, knowledge, math, document, verifier, trust-boundary, model-routing, LaTeX, and release-consistency regression contracts. Browser Assurance covers rendered LaTeX in the chat UI in addition to the existing Chromium/WebKit workspace suite.
