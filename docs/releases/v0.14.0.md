# v0.14.0 — NVIDIA Tools and Agent Actions

Дата: 6 августа 2026

## Что добавлено

Erma-модели получили ограниченный серверный tool calling через NVIDIA Chat Completions. Это не универсальный автономный агент: приложение предлагает инструменты только для подходящих запросов, выполняет их последовательно и затем передаёт проверенные результаты в обычную финальную генерацию.

Доступны шесть read-only инструментов:

- `search_documentation` — поиск по фиксированному внутреннему индексу документации;
- `search_patch_notes` — поиск и сравнение публичных записей версий;
- `get_service_status` — чтение внутреннего health snapshot;
- `calculate` — безопасный арифметический parser без `eval`;
- `search_local_archive` — поиск по временному ограниченному индексу из текущего браузера;
- `get_model_capabilities` — безопасное описание возможностей Erma без provider routing.

## Ограничения безопасности

- Серверный allowlist содержит только перечисленные функции.
- Аргументы закрыты JSON Schema с `additionalProperties: false`.
- Один запрос может выполнить максимум четыре вызова за три раунда.
- Parallel tool calls отключены.
- Каждый инструмент имеет собственный timeout 3 секунды.
- Произвольные URL, shell-команды, filesystem и универсальное выполнение JavaScript отсутствуют.
- Изменяющих состояние действий в v0.14.0 нет; будущие write-actions потребуют явного подтверждения пользователя.
- Журнал содержит только request ID, имя инструмента, статус и длительность. Аргументы, результаты и секреты не записываются.

## NVIDIA и reasoning

Tool planner запускается отдельно от финального ответа. Для Nemotron он передаёт `enable_thinking: false`, для DeepSeek — `thinking: false`. После завершения loop финальный ответ может использовать обычный выбранный пользователем режим reasoning, но уже без повторного доступа к tools.

## Интерфейс

Под ответом появляется отдельная карточка «AI использовал инструмент» / “AI used a tool”. Она показывает название функции, результат выполнения, длительность и только безопасные внутренние ссылки.

## Локальный архив

Полный архив остаётся в `localStorage`. С текущим запросом отправляется максимум 20 записей: ID сессии, название, проект, время изменения и короткий фрагмент последних сообщений. Снимок повторно проверяется на сервере, используется только в рамках запроса и не сохраняется.

## Совместимость

При ошибке planner, timeout инструмента или неподдерживаемом tool response обычный AI-запрос продолжается без инструментов. JSON и SSE transport сохраняют прежнее поведение; traces передаются в `meta.toolCalls`, а streaming дополнительно поддерживает событие `tool`.
