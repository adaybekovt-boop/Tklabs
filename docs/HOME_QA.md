# Erma homepage implementation and final QA

Final revision against main ad7a6c5. The replacement Erma brief is retained in .cdesign/INTENT.md; subsequent user review controls the final palette, caption removal and scene timing. This report supersedes QA for the rejected first cut.

## Result

The homepage inherits the same monochrome light/dark tokens as Models and Documentation, reuses SiteLogo and the application's body typography, and has no forced dark or orange palette. The actual 659x672 in-app viewport was checked, including scroll progression and navigation to Models. The source-scene heading, its paragraph and visible demo footnotes were removed as requested.

Native scroll controls independent product planes: composer, Auto route, answer, documentation, archive, revisions and final workspace. The model/archive wait for the answer to settle; composer clears during the close view; source placement uses measured answer geometry. The earlier draft disappears before the checklist enters. A single owner caches geometry and schedules animation frames only while settling. Film is enabled from 600x600; smaller/shorter windows use the readable unpinned document. Reduced motion and disabled JS keep the content available.

The example uses the current catalog and server selector, performs no AI request, and never writes to the real archive. Version buttons change only the example. Activity/Context/Task/Files follows current main's workspace. Open Erma preserves /playground's existing sign-in boundary. The release block uses repository data.

## Validation

- Typecheck and production build passed.
- ESLint: zero errors, six existing warnings in persistence/worker modules.
- Unit suite: 22 passed; integration suite: 293 passed after integrating current main.
- Nine homepage tests passed in desktop Chromium, mobile Chromium and mobile WebKit (27 passes). After the short-window fallback and capture addition, the final ten-test desktop suite passed again.
- Tests cover RU/EN at 1920x1080, 1440x900, 1280x800, 1024x768, 834x1112, 659x672 and 390x844; native CTA/auth destination; keyboard versions; no archive writes; forward/reverse scroll; resize; no-JS and reduced-motion cleanup.
- Regression checks compare actual computed page/action colors across home, Models and Documentation in both themes. At 13 intermediate scroll positions in both 1440x900 and 659x672, readable product planes must not intersect. Short 659x500 windows use the unpinned document.
- Manual in-app review checked the original monochrome reference pages, hero, route, answer/source and assembled workspace. Final screenshots are generated by the collision regression test. Earlier orange screenshots and recording are superseded.
